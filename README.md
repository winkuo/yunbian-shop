# 云边小卖部 · 数学闯关 v1.3

苏教版四年级上册数学同步练习 PWA。故事化、低压力、离线可用。
对照《产品规格书 V1.3》实现，单文件应用，无账号、无云端、无广告、无内购。

## 这是什么

- 🏮 云边小镇外婆的小卖部：7 个主线关卡 + 星光集市（全册综合），题目全部包装成理货、盘点、算账、接待客人的小店任务
- 🌱⭐ 双难度：简单帮工 / 能干帮工，各自独立题池
- 🎲 大题池随机抽题：每轮抽 6 题、本轮不重复，退出重进重新随机，防背题
- 💡 阶梯提示：第 1 次错→刘十三提示，第 2 次→锦囊卡片，第 3 次→示范思路（只引导，永不给答案）
- ⭐ 星光激励三选一（家长设置）：
  - A：攒星光换赵一鸣零食（申请→家长审核→7 天兑换凭证→过期自动退星）
  - B：虚拟物资收集彩蛋
  - C：纯刷题无奖励
- 🔒 关卡顺序锁（默认开）＋ 星光集市独立放行开关
- 🔊 有道美音朗读题干、✏️ 草稿手写板、🖼️ 插画收藏屋、📜 通关奖状

## 文件说明

| 文件 | 作用 |
|---|---|
| index.html | 全部程序（页面+题库+逻辑，双击即可玩） |
| manifest.webmanifest | PWA 清单（可安装到桌面/主屏） |
| sw.js | 离线缓存（仅在 http/https 下生效） |
| icon.svg | 应用图标 |

## 发布到 GitHub Pages（5 步）

1. 登录 github.com → 右上角 ➕ → **New repository**，名字随意（如 `yunbian-shop`），选 **Public**，不要勾任何初始化选项
2. 仓库页点 **uploading an existing file**，把本目录 4 个文件全部拖进去（index.html / manifest.webmanifest / sw.js / icon.svg）
3. 点 **Commit changes**
4. 仓库页 → **Settings** → 左侧 **Pages** → Branch 选 `main`（或 master）+ `/ (root)` → **Save**
5. 等 1 分钟，回到 Pages 页会显示访问地址，形如：
   `https://<你的用户名>.github.io/yunbian-shop/`

手机/平板浏览器打开这个地址，就能玩；首次打开后即可离线使用。
（若要自定义孩子名字、门店照片，改 index.html 顶部 `CONFIG` 后重新上传，见下。）

## 家长自定义（index.html 顶部 CONFIG）

```js
var CONFIG = {
  childName: "蓁宝",     // 凭证与奖状上的名字
  zmyImg: "",            // 赵一鸣门店照片：填图片链接，或把照片放同目录后填 "zmy.jpg"
  roundCount: 6,         // 每轮抽题数量
  dropChance: 0.3        // 模式B答题掉落物资概率
};
```

换照片最简单的方法：把门店照片命名为 `zmy.jpg` 和 index.html 放同一目录，再填 `zmyImg: "zmy.jpg"`。

## 家长端怎么用

- 首页 → 「外婆的设置」：切难度、切激励模式、开关顺序锁/集市放行、改兑换参数和零食黑名单
- 模式A：孩子在「外婆兑换台」提交申请 → 家长在同一页「家长审核」点通过/驳回 → 通过后生成 7 天兑换凭证（可截图），过期星光自动退回
- 所有进度只存在本机（localStorage），换设备/清浏览器数据会清空
